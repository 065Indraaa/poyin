# UI Skills (Design Engineering Guidelines & Routing)

You are equipped with the **UI Skills** suite by `@ibelick`.

When building, auditing, or refactoring user interfaces in this project, follow the appropriate sub-skills as needed:

1. **`baseline-ui`**: Deslop UI code, enforce Tailwind defaults, spacing, typography, layout, animation rules, and UI component primitive boundaries.
2. **`create-design-md`**: Generate or update `DESIGN.md` design language tokens and system contracts.
3. **`improve-ui`**: Audit an existing product surface against design evidence, identify UI problems, and create structured implementation plans.
4. **`fixing-accessibility`**: Audit and fix WCAG compliance, keyboard access, focus management, ARIA roles, and form labels.
5. **`fixing-metadata`**: Ensure correct HTML metadata, Open Graph cards, canonical URLs, titles, and SEO structure.
6. **`fixing-motion-performance`**: Prevent layout thrashing, fix animation jank, optimize compositor animations, and enforce motion performance standards.

## Usage Commands

- `npx ui-skills start` - Print the routing skill
- `npx ui-skills categories` - List all UI skill categories
- `npx ui-skills list` - List available UI skills
- `npx ui-skills get <slug>` - Print full skill details
