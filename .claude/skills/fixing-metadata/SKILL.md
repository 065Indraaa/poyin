# Fixing Metadata

Audit and fix page metadata for SEO and social sharing.

## Guidelines

1. **Title & Description**: Every page must have a descriptive title and plain-text meta description.
2. **Canonical URLs**: Canonical link must match the preferred page URL.
3. **Open Graph & Twitter Cards**: og:title, og:description, og:image (absolute URL), og:url, twitter:card ("summary_large_image").
4. **Icons & Favicons**: Stable favicon paths and Apple touch icon references.
